# Portfolio - Abdelilah Amalas

Mon portfolio professionnel d'ingénierie et développement web Full Stack (React, JavaScript, TypeScript, PHP, Laravel).

## 🚀 Fonctionnalités

- **Accueil & Hero** avec effet d'écriture dynamique et présentation professionnelle.
- **Compétences & Tech Stack** avec grille interactive et icônes Devicon.
- **Projets** avec recherche en temps réel et filtres par catégorie.
- **À Propos & Expériences** incluant le parcours et le stage au Secrétariat Général du Gouvernement (SGG).
- **Contact** avec formulaire interactif et notifications Toast.

## 🛠️ Stack Technique

- **Frontend**: React 19, Vite, Tailwind CSS, GSAP, Lucide Icons, TanStack Query.
- **Architecture**: Clean Architecture Frontend, 100% autonome et statique.

## 💻 Installation & Lancement local

```bash
# Ingestion des dépendances
npm install

# Lancement du serveur de développement
npm run dev

# Construction de la version de production
npm run build
```
